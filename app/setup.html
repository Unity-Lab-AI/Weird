NetworkFirst launch only, for the downloads. The game then runs offline, except the in-browser voice (Kokoro), which fetches its voice weights once on first use and caches them.

No NVIDIA GPU? The game still plays as text and emoji; image generation needs the GPU. AMD and Intel GPUs are not supported for images.
